🚀 دليل رفع النظام على GitHub Pages

خطوات تفصيلية لنشر نظام اختبار سحب العينات على الإنترنت مجاناً

1
إنشاء حساب GitHub (إن لم يكن لديك)

اذهب إلى github.com وأنشئ حساباً مجانياً.

  • اختر اسم مستخدم مناسب (مثال: health-trainer)
  • أكّد بريدك الإلكتروني
  • اختر الخطة المجانية Free
✅ الحساب المجاني يتضمن GitHub Pages مجاناً بدون أي تكلفة
2
إنشاء مستودع (Repository) جديد

بعد تسجيل الدخول:

  • اضغط على الزر الأخضر New أو اذهب إلى github.com/new
  • اكتب اسم المستودع: qr-training-app مهم
  • اجعله Public (مطلوب لـ GitHub Pages المجاني)
  • لا تضف README أو .gitignore
  • اضغط Create repository
⚠️ الاسم qr-training-app مهم لأنه سيُشكّل جزءاً من الرابط
3
تجهيز الملفات على جهازك

قم بتنزيل ملف qr-training-app.zip المرفق وافك ضغطه. ستجد هذا الهيكل:

📁 qr-training-app/
├── 📄 package.json
├── 📄 vite.config.js
├── 📄 index.html
└── 📁 src/
    ├── 📄 main.jsx
    └── 📄 App.jsx

ثم افتح package.json وعدّل هذا السطر:

"homepage": "https://YOUR-USERNAME.github.io/qr-training-app"

استبدل YOUR-USERNAME باسم مستخدمك على GitHub. مثال:

"homepage": "https://health-trainer.github.io/qr-training-app"
4
تثبيت Node.js (مرة واحدة فقط)

إذا لم يكن Node.js مثبتاً على جهازك:

  • اذهب إلى nodejs.org
  • نزّل النسخة LTS (الموصى بها)
  • ثبّتها بالإعدادات الافتراضية

للتحقق من التثبيت، افتح Terminal أو Command Prompt واكتب:

node --version
✅ يجب أن يظهر رقم مثل v18.0.0 أو أحدث
5
بناء ونشر التطبيق (3 أوامر فقط!)

افتح Terminal أو Command Prompt، انتقل لمجلد المشروع:

cd qr-training-app

ثم نفّذ هذه الأوامر بالترتيب:

# 1. تثبيت المكتبات (مرة واحدة)
npm install

# 2. بناء التطبيق
npm run build

# 3. النشر على GitHub Pages
npm run deploy
⏳ الأمر الأخير سيطلب منك اسم المستخدم وكلمة المرور (أو Personal Access Token) للـ GitHub
✅ بعد انتهاء الأوامر بنجاح، سيظهر: Published
6
تفعيل GitHub Pages من إعدادات المستودع

في حالة لم يعمل الرابط مباشرة، افعل هذا:

  • اذهب لمستودعك على GitHub
  • اضغط Settings (الإعدادات)
  • من القائمة الجانبية: Pages
  • تحت Source: اختر Deploy from a branch
  • اختر فرع gh-pages ومجلد / (root)
  • اضغط Save
⏳ انتظر 2-3 دقائق ثم افتح الرابط
7
🎉 رابطك الآن جاهز!

رابط تطبيقك سيكون:

https://YOUR-USERNAME.github.io/qr-training-app/

مثال عملي:

https://health-trainer.github.io/qr-training-app/
✅ هذا الرابط هو ما سيُشفَّر في رموز QR لكل متدرب
✅ يعمل على جميع الأجهزة والمتصفحات
✅ مجاني بالكامل — بدون انتهاء صلاحية
8
ملاحظة مهمة: مزامنة البيانات بين الأجهزة
⚠️ GitHub Pages = موقع ثابت

البيانات تُخزَّن في المتصفح (localStorage) وهذا يعني:
• المتدربون الذين يفتحون QR على أجهزتهم → نتائجهم تُحفظ في متصفحاتهم
• المدرب يرى النتائج فقط على الجهاز الذي يستخدمه

الحل للمزامنة الحقيقية: استخدام خدمة مثل Firebase أو Supabase (مجانية أيضاً)

للاستخدام في قاعة واحدة (الحل الأبسط):

  • افتح لوحة المدرب على جهاز المدرب
  • وزّع رموز QR المطبوعة على المتدربين
  • كل متدرب يؤدي الاختبار على جواله
  • في نهاية الجلسة، اطلب من كل متدرب تصوير شاشة نتيجته
  • أو اجمع الأجهزة وسجّل النتائج يدوياً في لوحة المدرب
💡
إذا طلب GitHub كلمة مرور عند النشر

GitHub لا يقبل كلمة المرور العادية للـ CLI، تحتاج Personal Access Token:

  • اذهب إلى: github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
  • اضغط Generate new token
  • اختر صلاحية repo
  • انسخ الـ Token واستخدمه بدلاً من كلمة المرور
